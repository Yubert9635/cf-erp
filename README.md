# Cloud ERP 进销存系统

> 基于 Cloudflare Workers + D1 + Hono + Vue 3 的轻量级进销存 ERP，零服务器成本、全球 CDN 加速、自带定时备份。

## 核心特性

- **零成本部署**：Cloudflare Workers 免费套餐即可运行，D1 数据库自带冗余
- **移动加权平均成本**：每次采购自动重算均价，销售时快照固化历史毛利
- **维修管理**：维修单登记、配件领用扣库存、手填件（不入库商品/拆机件）、诊断维修说明、状态流转（维修中→已完成→已取机）、打印维修单
- **手机扫码**：摄像头实时识别条码，自动匹配商品录入（采购/销售/维修/商品登记）
- **多用户权限**：管理员 / 普通员工 / 销售收银员三级角色，按模块授权
- **安全**：SHA-256 密码哈希、HMAC 签名 Session Cookie
- **数据**：本地全量 JSON 备份与还原、WebDAV 远程定时自动备份（坚果云 / 群晖 / AList 等）、保留天数自动清理

## 成本核算机制

系统采用 **移动加权平均法** 进行成本与毛利核算：
- 每次采购入库时，自动根据 `(原库存×原均价 + 新入库量×新进价) / 总库存` 重算移动加权成本
- 销售出库 / 维修领用时，即时对当时成本均价进行**快照固化**，确保历史毛利不受日后进价波动影响
- 支持手动指定并**锁定成本均价**，锁定后不随采购流水变动
- 任何历史单据修改或删除后，系统自动全量重放重算，确保账实严格相符

## 部署到 Cloudflare（全新干净部署）

部署后默认是一个**全新的空进销存系统**，包含管理员默认账号（`admin` / `admin123`），不包含任何业务数据：

1. 登录 Cloudflare 并创建 D1 数据库：

   ```sh
   npx wrangler login
   npx wrangler d1 create cf-erp
   ```

2. 将上一步输出的 `database_id` 填入 `wrangler.jsonc`。

3. 部署到 Cloudflare Workers：

   ```sh
   npm run deploy
   ```

4. 访问你的 Workers 域名（建议绑定自定义域名），输入默认账号 `admin`，密码 `admin123` 登录。

5. 登录后进入「系统设置」：
   - 修改店铺名称、电话、地址
   - 修改默认密码或添加员工账号
   - 上传历史备份文件一键还原数据
   - 配置 WebDAV 远程自动备份

### 双账号部署（GitHub Actions 自动部署）

项目支持通过 GitHub Actions 自动部署到**两个 Cloudflare 账号**：

1. 在 GitHub 仓库 Settings → Secrets 中添加：
   - `CF_API_TOKEN_ACC1` — 账号1 的 Cloudflare API Token
   - `CF_API_TOKEN_ACC2` — 账号2 的 Cloudflare API Token

2. 将两个账号的 D1 `database_id` 分别填入 `wrangler.acc1.jsonc`（账号1）和 `wrangler.jsonc`（账号2）。

3. 推送到 `main` 分支即自动部署到两个账号，静态资源带 `run_id` 版本号自动破缓存。

```sh
npm run dev        # 启动本地服务：http://127.0.0.1:8787
```

运行自动化集成测试：

```sh
node test/api.test.mjs
node test/retail.test.mjs
```
